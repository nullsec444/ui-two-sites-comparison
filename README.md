# Public demo reconstruction research

Kobra (kobra.systems) and Movements (movements.dev), original public demos versus reconstructed modules. This is an explicit partial recovery, not a claim of complete source or equivalent behavior.

Open index.html through a static server, or use GitHub Pages. Search covers both sites. Every route has Original demo / Inspect replay buttons above one shared iframe, with source collapsed below it.

The live demos are executable code, not screenshots and not original-site mirrors. Original public demo functions use a small loader with React/DOM normalized to 19.2.8. Reconstructed modules restore JSX from public runtime calls, retaining minified identifiers where author names were unavailable. Some exact free registry implementations are integrated and are labeled separately. Exact free source and official npm distributions are preserved without claiming they are decompiled author TSX.

Read REPORT.md, manifest.json and acceptance-report.json for exact computed coverage, remaining blockers, visual differences and the strict acceptance result. A successful render or identical DOM/screenshot does not prove interaction or animation equivalence. No authentication, payment, or registry access controls were bypassed.
